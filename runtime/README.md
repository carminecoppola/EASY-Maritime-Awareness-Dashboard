# Runtime Layout

This directory contains everything the dashboard needs to run inference without depending on `easy-maritime-awareness`.

## `models/`

Holds the model artifacts copied from the model repository.

- `easy_v1_best_rgb.onnx` is the preferred inference model.
- `easy_v1_best_rgb.pt` is the fallback backup model.
- Optional files such as `classes.yaml` or `model_metadata.json` are not present in the source repository at copy time, so they are not included here.

## `config/`

Contains runtime configuration used by the dashboard inference pipeline.

- `inference_config.yaml` defines:
  - the preferred and fallback model paths
  - the model type
  - the class names
  - the confidence threshold
  - the IoU threshold
  - the input size

## `sessions/`

Used to store per-session runtime artifacts generated by inference.

- detection JSON files
- snapshots
- session logs

## `replay/`

Used for Replay/Demo assets.

- video files
- images used for replay runs

## `logs/`

Used for dashboard runtime logs.

- application logs
- inference diagnostics

## ONNX Smoke Test

To validate the ONNX model before dashboard integration, run:

```bash
python3 scripts/test_onnx_inference.py
```

You can also pass a specific image:

```bash
python3 scripts/test_onnx_inference.py --image /path/to/image.jpg
```
